# TripSplit - Test Plan and Results

_Generated by `docs/build_test_plan.py` on 2026-10-05 from a real run of the automated suite._

**Automated run:** `91 passed in 15.53s`

The API tests run against SQLite (a schema twin of the MySQL schema, `backend/tests/schema_sqlite.sql`) so they need no database server. They exercise all application logic and SQL, but MySQL-specific behaviour (CHECK enforcement on 8.0.16+, `SELECT ... FOR UPDATE`, DECIMAL storage) should also be confirmed once on a real MySQL server using `database/schema.sql`, `backend/seed_demo.py` and `database/sample_queries.sql`.
